# تصميم + كتابة محتوى + تعليق صوتي

## 1. اجمع المدخلات (سؤال واحد فقط إن نقص شيء أساسي)
- المنتج/الموضوع، الجمهور، المنصة (إنستغرام، تيك توك، يوتيوب، X، لينكدإن)، اللغة واللهجة، الهدف (بيع، توعية، تسجيل).
- إن لم يُذكر شيء: افترض إنستغرام، عربية فصحى مبسطة، مدة 30 ثانية، هدف البيع. واذكر الافتراض في سطر.

## 2. المحتوى المكتوب
- **العنوان (Hook):** 3 بدائل، كل واحد ≤ 8 كلمات.
- **النص الأساسي:** فقرة قصيرة بأسلوب: مشكلة ← حل ← فائدة ← دعوة لاتخاذ إجراء (CTA).
- **الكابشن:** ≤ 150 كلمة + 5–10 هاشتاقات مناسبة للمنصة.

## 3. التصميم
- قدّم مواصفات واضحة: المقاس حسب المنصة (1080×1080 بوست، 1080×1920 ستوري/ريلز، 1920×1080 يوتيوب)، لوحة ألوان (3 ألوان بـ HEX)، خطوط عربية (Cairo, Tajawal, IBM Plex Sans Arabic)، توزيع العناصر.
- عند الطلب أو إن كان مفيداً: نفّذ التصميم فعلياً كملف HTML/SVG بنفس المقاس، باتجاه `dir="rtl"`، وصدّره صورة PNG بـ Playwright إن لزم.
- إن توفّرت أدوات تصميم متصلة (Canva، Figma، Adobe) فاستخدمها بدل HTML.

## 4. نص التعليق الصوتي (Voice-over)
اكتبه جدولاً مقسّماً زمنياً:

| الوقت | المشهد (ما يظهر) | التعليق الصوتي | ملاحظة أداء |
|---|---|---|---|
| 0–3ث | ... | الـ Hook | نبرة حماسية |

- السرعة: ~2.5 كلمة/ثانية بالعربية (30 ثانية ≈ 75 كلمة).
- جمل قصيرة سهلة النطق، وشكّل الكلمات الملتبسة.
- علّم الوقفات بـ `/` والتشديد بـ **عريض**.

## 5. توليد الصوت (اختياري)
- إن طلب المستخدم ملفاً صوتياً: جرّب أداة TTS متاحة (مثل `edge-tts` بصوت `ar-SA-HamedNeural` أو `ar-EG-SalmaNeural`)، واحفظ الناتج MP3 وأرسله.
- إن لم تتوفر أداة: سلّم النص جاهزاً للصق في ElevenLabs أو أي مولّد صوت، مع اقتراح نوع الصوت.

## 6. التسليم
باختصار وبهذا الترتيب: العناوين ← النص ← الكابشن ← مواصفات/ملف التصميم ← جدول التعليق الصوتي ← ملف الصوت (إن وُجد). بلا مقدمات.
